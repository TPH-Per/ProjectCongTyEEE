## 1. Fix lỗi `npm run dev` không khởi chạy được

### Mô tả

Chạy `npm run dev` (tương đương `vite`) thì Vite server báo lỗi:

```
[UNRESOLVED_ENTRY] Cannot resolve entry module index.html.
```

Vite không tìm thấy file `index.html` ở thư mục gốc — đây là file entry point bắt buộc mà Vite cần để biết load module nào.

### Phân tích nguyên nhân

- Vite yêu cầu file `index.html` ở thư mục gốc project作为 HTML entry point.
- Kiểm tra bằng `glob`: chỉ tìm thấy `index.html` trong `playwright-report/` (không liên quan).
- File `src/main.ts` mount Vue app vào `#app`, `src/App.vue` có template `<div id="app">` — nhưng thiếu HTML shell để Vite khởi tạo.

### Files tạo/sửa

| File | Hành động | Mô tả |
|------|-----------|-------|
| `index.html` | **Tạo mới** | HTML entry point cho Vite, chứa `<div id="app">` + `<script type="module" src="/src/main.ts">` |

### Chi tiết fix

Tạo file `index.html` ở thư mục gốc:

```html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Restaurant Booking UI</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>
```

### Verification

- `npx vite build` — ✅ pass (3938 modules transformed, exit code 0)
- Các warning `@tailwind` / `@apply` từ lightningcss minifier không phải lỗi, chỉ là cảnh báo CSS minify.

## 2. Fix thiếu key i18n (console warnings)

### Mô tả

Console browser báo 3 warning `[intlify] Not found`:

```
[intlify] Not found 'sidebar.open_shift' key in 'vi' locale messages.
[intlify] Not found 'sidebar.shift_summary' key in 'vi' locale messages.
[intlify] Not found 'sidebar.ra_ca' key in 'vi' locale messages.
```

### Phân tích nguyên nhân

- Component `src/layouts/ReceptionLayout.vue` (dòng 127, 135, 143) gọi `t('sidebar.open_shift')`, `t('sidebar.shift_summary')`, `t('sidebar.ra_ca')`.
- 3 locale files (`vi.ts`, `en.ts`, `ja.ts`) có `sidebar.shift`, `sidebar.close_shift`, `sidebar.exit_shift` nhưng **thiếu** 3 key trên.
- `src/stores/useLanguageStore.ts` (fallback dict) có 3 key này cho `vi` và `en`, nhưng **thiếu hoàn toàn cho `ja`**.

### Files tạo/sửa

| File | Hành động | Mô tả |
|------|-----------|-------|
| `src/locales/vi.ts` | **Sửa** | Thêm 3 key: `sidebar.open_shift` → "Mở ca", `sidebar.shift_summary` → "Tổng kết ca", `sidebar.ra_ca` → "Ra ca" |
| `src/locales/en.ts` | **Sửa** | Thêm 3 key: → "Open Shift", "Shift Summary", "Close Shift" |
| `src/locales/ja.ts` | **Sửa** | Thêm 3 key: → "シフト開始", "シフト概要", "退出" |
| `src/stores/useLanguageStore.ts` | **Sửa** | Thêm 5 key `sidebar.*` (shift, open_shift, shift_summary, ra_ca, close_shift) cho block `ja` — trước đó JA block hoàn toàn thiếu `sidebar.*` |

### Chi tiết fix

#### Locale files (`vi.ts`, `en.ts`, `ja.ts`)

Thêm 3 key ngay sau dòng `sidebar.exit_shift` hiện có:

```typescript
// vi.ts
'sidebar.open_shift': 'Mở ca',
'sidebar.shift_summary': 'Tổng kết ca',
'sidebar.ra_ca': 'Ra ca',

// en.ts
'sidebar.open_shift': 'Open Shift',
'sidebar.shift_summary': 'Shift Summary',
'sidebar.ra_ca': 'Close Shift',

// ja.ts
'sidebar.open_shift': 'シフト開始',
'sidebar.shift_summary': 'シフト概要',
'sidebar.ra_ca': '退出',
```

#### `useLanguageStore.ts` — JA fallback dict

Block `ja` trong dict hoàn toàn thiếu `sidebar.*`. Thêm sau section `reception.ignore`:

```typescript
ja: {
  // ... existing reception keys ...

  'reception.ignore': '無視',

  // Sidebar
  'sidebar.shift': 'シフト',
  'sidebar.open_shift': 'シフト開始',
  'sidebar.shift_summary': 'シフト概要',
  'sidebar.ra_ca': '退出',
  'sidebar.close_shift': 'シフト終了',

  // Dashboard Keys
  // ...
}
```

### Verification

- `npx vue-tsc --noEmit` — ✅ pass (0 errors, exit code 0)
- Các warning `[intlify] Not found` sẽ biến mất sau khi restart Vite.

## Ghi chú kỹ thuật

- **`index.html`** là file bắt buộc ở thư mục gốc cho mọi Vite project — Vite dùng nó làm HTML entry point, không thể đặt trong `src/`.
- **i18n fallback layer**: Project có 2 lớp i18n — Vue I18n (`src/locales/*.ts`) là lớp chính, `useLanguageStore.ts` dict là fallback. Khi key không tìm thấy ở lớp chính, `useLanguageStore.t()` mới tra dict. Tuy nhiên, Vue I18n vẫn báo warning `[intlify] Not found` trước khi fallback kích hoạt — nên cần thêm key vào cả 2 lớp.
- **Block `ja` trong `useLanguageStore.ts`** thiếu toàn bộ `sidebar.*` — có thể do block JA được tạo sau và sao chép thiếu. Đã bổ sung 5 key đầy đủ.
- Type-check (`vue-tsc --noEmit`) và build (`vite build`) đều pass clean sau mọi thay đổi.

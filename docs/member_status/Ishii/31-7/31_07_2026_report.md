## 3. Fix lỗi /select-branch — Mock Data Branches

### 3.1. Vấn đề

Trang `/select-branch` (`SelectBranchView.vue`) gọi `useBranch().listBranches()` để tải danh sách chi nhánh. Hàm này chỉ query Supabase trực tiếp, không có mock data fallback. Khi Supabase chưa cấu hình hoặc query lỗi → trang hiển thị "Không có chi nhánh hoạt động".

### 3.2. Nguyên nhân

`listBranches()` trong `src/composables/useBranch.ts`:
- Không check `isSupabaseConfigured`
- Không có try/catch → error throw lên `SelectBranchView.vue` → hiển thị error message
- Không có mock data fallback

Trong khi đó, `customerApi.ts` đã có `MOCK_BRANCHES` (2 chi nhánh) và fallback đúng cho customer flow.

### 3.3. Giải pháp

**File sửa:** `src/composables/useBranch.ts`

1. Import `isSupabaseConfigured` từ `@/lib/supabase`
2. Import `BRANCH_IDS` từ `@/lib/branch-constants` (sử dụng UUID thực tế)
3. Thêm `MOCK_BRANCHES` array với 2 chi nhánh:
   - **Ngưu Cát Quận 1** (B001, UUID: `b1000000-0000-0000-0000-000000000001`)
   - **Ngưu Cát Phú Nhuận** (B002, UUID: `b1000000-0000-0000-0000-000000000002`)
4. Thêm `if (!isSupabaseConfigured) return MOCK_BRANCHES` ở đầu `listBranches()`
5. Wrap Supabase queries trong `try/catch`, fallback về `MOCK_BRANCHES` khi lỗi

### 3.4. Verification

- `vue-tsc --noEmit`: PASS (0 errors)
- Mock data sử dụng đúng UUID từ `branch-constants.ts` → consistent với toàn bộ hệ thống
